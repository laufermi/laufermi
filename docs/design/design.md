# Design reference

The generated homepage concept is `home-concept.png`. It is an implementation reference, not a site asset or a user-approved design. Generated with the built-in Image Gen tool from this brief: a complete typography-only Laufermi personal homepage, ivory #f6f5f0, ink #252824, olive #626b45, serif headings, sans-serif body, open ruled sections, Home/Articles/Resources/GitHub navigation, the existing motto, an honest article empty state, selected resource categories, and GitHub/RSS footer. No biography, fabricated articles, imagery, cards, gradients, or decorative hero labels.

The system uses a 1320px maximum shell, 60px desktop gutters at the 1440px reference viewport, a 20% section-label column, 64px section spacing, Times New Roman headings and system sans body. Hero heading is 116px at full size, section headings 48px, body 20px. Rules use muted olive-gray. Underlined olive text links and thin SVG arrows are the only action family. Mobile stacks the hero and section label above content, keeping all navigation visible.

Allowed homepage copy follows the reference: `laufermi.`, Home, Articles, Resources, GitHub; `Do one thing and do it well.`; the personal-space description; `Explore the resources`; `01 / ARTICLES`; `Room for the next idea.`; the empty-state description; `All articles`; `02 / RESOURCES`; `A collection worth returning to.`; Methodologies, Principles, Tools; footer Laufermi, motto, GitHub, RSS. Published content replaces the article empty state automatically.

Other surfaces extend these same families: article index and article reading layout, searchable resource rows with category navigation, preserved privacy text, and a 404 page. Search and article metadata are functional requirements beyond the homepage concept.

## Brand update

The current site identity is `FM6MHZ` in the wordmark, titles, social metadata, and RSS. The footer reads `FM6MHZ` and `Simply shaped, deeply made`. The user requested that the meaning not be explained. The subsequent UI refinement uses a compact sans-serif wordmark, olive italic second headline line, 1180px content width, lighter rules, smaller section headings, active navigation underlines, restrained hover states, and responsive spacing. These user-requested refinements supersede the original concept. GitHub account and repository URLs remain unchanged.

The user selected wordmark proposal 01 (Continuous): one uppercase `FM6MHZ` silhouette, olive FM and ink 6MHZ, matching weight and height, tight spacing, no tuning scale. The header uses live text with a heavy sans-serif font stack.
